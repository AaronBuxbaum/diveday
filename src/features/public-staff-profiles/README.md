# Public staff profiles

Each staff member writes their own optional public introduction in Account settings. Profile consent is a separate, default-off choice from the existing departure-name consent. The shop's Features switch hides introductions everywhere without withdrawing anybody's choice.

The entry point exports self-profile reads and writes, the public shop projection, and assigned departure profiles. Public projections include only live staff with active accounts, strip identifiers, and use the existing crew-away rule for assigned staff. Pictures are uploaded through first-party storage; the editor accepts no pasted URL and can retain or delete only pictures already on its own row. Withdrawal clears the profile and durably retires its pictures. Export and erasure cover the content and media.
