# Overnight improvement prompts — 2026-08-04

Ten self-contained prompts, each meant to be pasted into its own Fable session and run in
parallel. Each prompt carries its own goal, an explicit Opus-subagent delegation plan, and a
"Done when" contract the session must loop against until every item is true — ending with a
ready-for-review PR on its own branch.

Every prompt is grounded in work the repo's own docs already call for: the roadmap
(`docs/product/features/roadmap.md`), the prompt-ready AI/ML tasks (`docs/product/features/ai-ml.md`),
the brainstorm quick wins (`docs/product/features/brainstorm.md`), and the pagination ADR's named
stragglers. Nothing here touches the human-owned gates (H-*/V-* in `docs/product/human-decisions.md`).

## Run notes (for the human dispatching these)

- **Parallel-safe by design**: each prompt owns disjoint primary paths and declares them in its PR
  description. The unavoidable shared hotspots are append-heavy files — `src/i18n/locales/*/staff.json`
  and `diver.json`, `e2e/visual.spec.ts`, `scripts/route-coverage.json`, and one sentence in
  `AGENTS.md` — where conflicts will be trivial "both added a block" merges.
- **Merge order doesn't matter.** If Prompt 8's new gates fail after another PR merges, the failing
  addition is a genuine violation of a rule that already exists in prose — fix the addition, not
  the gate.
- Prompts 3–7 and 10 implement tasks specified in `docs/product/features/ai-ml.md`; that file notes
  "a human decides what actually gets built" — your morning PR review is that decision. Close any
  PR you don't want; nothing merges itself.
