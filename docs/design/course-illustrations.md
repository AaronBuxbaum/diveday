Built-in image generation was used with those two references and `transparent_background: false`; the tool did not expose a model, seed, quality, or explicit size parameter. Masters are 1536 × 1024 PNGs. Delivery assets are WebP encoded with `cwebp -q 75`.

The following records preserve the exact prompt for each selected image. Generation is nondeterministic; these instructions describe the selected generation, not a guarantee of identical output.
