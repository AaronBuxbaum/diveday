Design language

Clearwater

How a DiveDay surface is built. Same palette, same type family, same primitives underneath — a different default composition. Water this clear is water you don’t see.

Type leads.

Hierarchy is carried by size, weight and space. Borders, fills and buttons are the last tools, not the first.

Groups own shared facts.

A date, a departure, a state, a count — said once in the group header, never repeated down the rows at equal weight.

Elevation is earned.

Everything at rest is flat: hairline, no shadow. A shadow means the thing is floating above the page — a menu, a sheet, a toast.

Two grouped anatomies are the default. The card stack retires.
