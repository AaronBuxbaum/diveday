The diagnosis, top-down

None of this is a missing primitive. The primitives exist and most are well adopted — buttons in 162 files, one control class in 461 places, one page header in 114 files, one empty state in 33, one chrome bar shared by staff and public. The seams come from five design passes in twelve days (Clearwater 08-27, Reef 09-01, Reef-all-the-way-down 09-04, Before-you-ask 09-06, Nothing-from-nowhere 09-07), each adding a vocabulary — a panel, a dial, a moment, a stage word, a fold — and none deleting the previous one. Three grammars now coexist on one screen: Clearwater's bare ledger, Reef's soft panel, and per-page inventions that predate both. The fix is not another vocabulary. It is one grammar for six jobs — width, header, group, row, add, state — with every second spelling deleted and a guard holding each at one, and then, if the owner wants "wow", a surface change that keeps that grammar.
