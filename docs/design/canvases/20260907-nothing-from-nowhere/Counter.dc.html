How the gap closes

Before the list changes, each row’s position is read; after it changes, each row is set back to where it was by transform and released to slide to where it now is. Nothing the browser lays out is animated, which is the rule the disclosure and the bar already keep. The leaving row is out of the flow the moment it starts to sink, so the rows beneath begin sliding on the same frame.

Where else a row leaves or moves

The manifest roster when a diver is removed (the one exit doing explanatory work today; the rows beneath jump). The home’s station when a blocker clears and the row goes. The wait list when a seat is offered. The board’s day when a departure moves. Each takes the same slide; none adds a control.

What renders otherwise

A reduced-motion reader: the row sinks in one frame and the rows beneath jump, as today. The roll call: the row leaving already moves there and the slide beneath it waits on H-69 c; nothing on the roll call moves before the server has the tap, and its head count never rolls.
