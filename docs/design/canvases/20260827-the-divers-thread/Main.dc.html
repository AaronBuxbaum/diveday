The diver’s thread

One link, the whole way

A diver’s trip is one thread: find a boat, book it, get ready, dive, glow. Booking already lands on the readiness link (ADR 20260820); this design keeps that link as the home of everything after — including the afterglow.

One measure.

Every page a booked diver walks reads at the same column width, phone and desktop alike. The measure never changes mid-thread.

Status is said once.

The spine’s figure and the next step’s name carry the whole state. No banner, receipt and progress bar repeating each other.

Coral is earned three times.

Money resolves in one block.

The pitch sells; the thread prepares.
