# Selected audit evidence

These images show the local synthetic Blue Mantis demo at the audited baseline. They are evidence
of particular rendered states, not production screenshots or proposed designs. JPEG compression
preserves the original pixel dimensions; use the source/test descriptions for dynamic behavior.
The local source filenames and dimensions are listed in [manifest.json](manifest.json).

No capability URLs, authentication storage or private browser metadata are included. Names and
contact information are seeded demo data. The security page's unusually large session count was
created by repeated audit sign-ins; the account-session idea concerns intelligible labels, not
that artificial count.
