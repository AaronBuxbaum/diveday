# Dive-domain glossary

Domain terms agents must use correctly — in code, UI copy, and data models. When you introduce a
new domain concept, define it in the same PR, in the domain file it belongs to under
[glossary/](glossary/): one entry per term, starting `- **Term** —`.

This page is generated by `node scripts/check-glossary.mjs --write` and `pnpm check:glossary`
fails while it is stale. Grep the domain files for a term; this index says which file holds it.
