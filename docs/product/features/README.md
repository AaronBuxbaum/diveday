## Promote an idea once

Search current code, issues and PRs before filing. Preserve the human's actual decision; an audit
recommendation is not approval. Reuse an existing issue, or file a narrowly scoped issue with
acceptance and verification. Follow [the issue workflow](../../agents/issue-tracker.md).
