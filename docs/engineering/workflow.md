# Engineering workflow index

This page routes you to the current workflow for each kind of work. The linked skill or policy is
the operating source; this index does not restate its steps or definition of done.

- **Build a feature:** [new-feature skill](../../.agents/skills/new-feature/SKILL.md) for context,
  slice, domain-first work, design, documentation, and delivery order.
- **Verify before commit or push:** [verify skill](../../.agents/skills/verify/SKILL.md) for local
  checks, observed behavior, visual evidence, push and CI gates, and honest reporting.
- **Route follow-ups:** [issue-tracker policy](../agents/issue-tracker.md#filing-a-follow-up) and
  [verify filing steps](../../.agents/skills/verify/filing.md) for issue categories, mechanics, and
  Notes comments.
- **Open, update, and land stacked pull requests:** [stacked-prs skill](../../.agents/skills/stacked-prs/SKILL.md).
- **Choose functional and visual coverage:** [testing strategy](testing.md) and
  [e2e-and-visual skill](../../.agents/skills/e2e-and-visual/SKILL.md).
- **Review a user-facing surface:** [design-review skill](../../.agents/skills/design-review/SKILL.md).
- **Explain CI image differences:** [visual-triage skill](../../.agents/skills/visual-triage/SKILL.md).

Product truth belongs in `docs/`; execution order and check mechanics belong in the linked skills
and repository scripts. When a process changes, update its operating source and this index only if
the route changes.
